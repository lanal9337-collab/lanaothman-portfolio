# Lana Othman Portfolio — GitHub Starter

This is a clean static rebuild based on the structure and visual language of the current portfolio:
- editorial/minimal layout
- large typography
- numbered sections
- neutral paper-like background
- thin rules and generous whitespace
- lightweight scroll-reveal effects
- responsive mobile layout

## Files

- `index.html` — all portfolio content
- `style.css` — all colors, typography, spacing and layout
- `script.js` — small reveal animation

## GitHub Pages

1. Create a new GitHub repository.
2. Upload these three files to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Open the generated Pages URL.
